An agent can start the editor, run something, read the console and correct
itself, which takes a whole class of failure off a reviewer's desk. The more
useful surprise was that a model with a live editor to talk to is very good at
reading prefabs and the running scene hierarchy, which is the half of a Unity
project that source-level tooling never reached.
